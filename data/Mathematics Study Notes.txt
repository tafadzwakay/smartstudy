Comprehensive Mathematics Notes (Forms 1–4, based on Zimbabwe syllabus)
Overview
These notes are organized in exam-revision style and cover the major Forms 1–4 mathematics syllabus areas: number systems, algebra, geometry, mensuration, trigonometry, statistics, probability, graphs, and transformations. Each section includes definitions, formulas, worked examples, and exam tips.
 
FORM 1 MATHEMATICS
Chapter 1: Real Numbers and Operations
1.1 Number Systems
Real numbers include:
•	Natural numbers: 1, 2, 3, ...
•	Whole numbers: 0, 1, 2, 3, ...
•	Integers: ..., -2, -1, 0, 1, 2, ...
•	Rational numbers: can be expressed as p/q where q  0
•	Irrational numbers: cannot be written as exact fractions (e.g. 2, π)
Laws of operations
•	BODMAS: Brackets, Orders, Division, Multiplication, Addition, Subtraction
•	Commutative law: a + b = b + a
•	Associative law: (a + b) + c = a + (b + c)
•	Distributive law: a(b + c) = ab + ac
Standard form
A number in scientific notation:
• a × 10^n, where 1  a < 10
Example: 450000 = 4.5 × 10^5 0.0032 = 3.2 × 10^-3
 
Chapter 2: Fractions, Ratios, Percentages
Key formulas
•	Percentage = (part / whole) × 100
•	Profit = selling price  cost price
•	Profit % = (profit / cost price) × 100
•	Simple interest = PRT / 100
Example
Find 20% of 360: 20/100 × 360 = 72
 
Chapter 3: Algebraic Expressions
Terms
•	Constant: fixed value
•	Variable: unknown represented by letters
•	Coefficient: numerical multiplier
Simplification
3x + 2x  x = 4x 2a + 3b cannot be simplified further
Expansion
a(b + c) = ab + ac
Example: 3(x + 4) = 3x + 12
 
FORM 2 MATHEMATICS
Chapter 4: Linear Equations
Formula
ax + b = c x = (c  b)/a
Example
3x + 5 = 17 3x = 12 x = 4
Simultaneous equations
Method: substitution or elimination
Example: x + y = 8 x  y = 2 Add equations: 2x = 10 x = 5, y = 3
 
Chapter 5: Geometry
Angle facts
•	Straight line = 180°
•	Around a point = 360°
•	Triangle sum = 180°
•	Quadrilateral sum = 360°
Parallel lines
•	Alternate angles are equal
•	Corresponding angles are equal
•	Co-interior angles sum to 180°
 
FORM 3 MATHEMATICS
Chapter 6: Quadratic Equations
General form
ax² + bx + c = 0
Factorisation
x² + 5x + 6 = 0 (x + 2)(x + 3) = 0 x = -2 or -3
Quadratic formula
x = (-b ± (b²  4ac)) / 2a
Discriminant
D = b²  4ac
•	D > 0 two real roots
•	D = 0 equal roots
•	D < 0 no real roots
 
Chapter 7: Trigonometry
Right-angled triangle SOH CAH TOA:
•	sin θ = opposite/hypotenuse
•	cos θ = adjacent/hypotenuse
•	tan θ = opposite/adjacent
Pythagoras theorem
a² + b² = c²
Example
Sides 3 and 4: c² = 3² + 4² = 25 c = 5
Sine rule
a/sinA = b/sinB = c/sinC Cosine rule
c² = a² + b²  2ab cos C
 
FORM 4 MATHEMATICS
Chapter 8: Mensuration
Perimeter and area
Rectangle:
•	Area = l × w
•	Perimeter = 2(l + w) Triangle:
•	Area = 1/2 bh Circle:
•	Area = πr²
•	Circumference = 2πr
Solids
Cylinder:
•	Volume = πr²h Cone:
•	Volume = 1/3 πr²h
Sphere:
•	Volume = 4/3 πr³
•	Surface area = 4πr²
 
Chapter 9: Graphs and Functions
Gradient
m = (y₂  y₁)/(x₂  x₁)
Equation of straight line y = mx + c where:
•	m = gradient
•	c = y-intercept
Distance between two points
[(x₂x₁)² + (y₂y₁)²]
Midpoint
((x₁+x₂)/2, (y₁+y₂)/2)
 
Chapter 10: Statistics
Mean
Mean = sum of values / number of values
Median
Middle value after arranging data
Mode
Most frequent value
Range
Highest  lowest
Frequency tables
Use tally marks and cumulative frequencies.
Chapter 11: Probability
Formula
P(E) = number of favorable outcomes / total outcomes
0  P(E)  1
Example
Rolling a die, probability of getting 3: 1/6
Complement: P(not E) = 1  P(E)
